🚀 Aegis-IV: AI & Space Exploration Interactive 3D Explainer

An interactive 3D WebGL web application and simulation showcasing how Artificial Intelligence empowers modern and future deep-space missions, Mars exploration rovers, and autonomous space probes.

🌟 Key Features

1. 🛸 Interactive 3D Model Explorer

Orbit Controls: Full 360-degree rotation, pan, and zoom around the Aegis-IV Spacecraft.

3D Pinpoint Hotspots: Floating interactive 3D hotspots pinned to core systems (Optical AI Core, AutoNav LiDAR, AEGIS ChemCam, RTG Core, and Deep Space Antenna Array).

Detailed Dynamic Telemetry: Real-time HUD gauges displaying AI Confidence Index, Neural Latency, and Optical Data Bus Bandwidth.

2. 🔬 X-Ray Internal Diagnostic Core View

Dynamic translucent hull rendering revealing internal hardware components.

Highlights neuromorphic optical processing chips, fiber optic lines, reaction wheels, and radioisotope thermal generators.

3. 🎮 Autonomous Flight Simulator

Pilot the Aegis-IV probe across low-gravity Martian terrain featuring craters, boulders, and dynamic dust wind physics.

Flight Controls: Keyboard controls for Pitch, Yaw, Acceleration, Ascent, and Descent.

AI Autopilot Mode: One-click autonomous pathfinding vector alignment toward terrain target waypoints.

4. 🎛️ Live AI Parameter Tuning & Hazard Radar

Real-time parameter sliders for AI Sensitivity, Terrain Hazard Density, and Thruster Energy Output.

Interactive 3D scanning laser overlay and dynamic mini-radar hazard map sweep.

5. 📚 Integrated Knowledge Hub & Audio

Educational modal windows detailing real-world NASA/ESA AI algorithms (AutoNav, AEGIS Target Selection, SLAM, Anomaly Detection).

Synthesized procedural Web Audio soundscapes for thrusters, laser scans, and telemetry feedback.

🛠️ Technology Stack

3D Rendering: Three.js (WebGL Framework)

UI & Styling: Tailwind CSS & Google Fonts (Orbitron, Rajdhani, Share Tech Mono)

Icons: FontAwesome 6

Audio Engine: Web Audio API (Synthesized Real-time Audio Oscillators)

🚀 Quick Start / Local Setup

No build steps or package installations (npm/node) required! The app runs directly in any modern browser.

Clone or download this repository:

git clone https://kundushivam38-boop.github.io/Project-1-Thinking-in-HTML/



Open index.html in your web browser (Chrome, Edge, Firefox, or Safari).

🌐 Deploy to GitHub Pages

Go to your repository settings on GitHub.

Navigate to Pages on the left menu.

Under Branch, select main and root /.

Click Save. Your 3D app will be live at https://kundushivam38-boop.github.io/Project-1-Thinking-in-HTML/
